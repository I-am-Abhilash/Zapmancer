## My strongest recommendation for ScriptSide

I would make the visual language **very different from Zapmancer**.

### Zapmancer

**Visual personality:**

> Bold · Dynamic · Professional · Technology · Marketplace

The landing page says:

> **"Let's get something done."**

### ScriptSide

**Visual personality:**

> Editorial · Minimal · Calm · Intelligent · Human

The landing page says:

> **"Let's explore an idea."**

For ScriptSide, I would use **large editorial typography, generous whitespace, subtle borders,
restrained animations, high-quality article imagery, and minimal UI chrome**. The page should feel
like the visitor has entered a place where **content is the hero**.

Most importantly, I would make the landing page **dynamic from day one**. Instead of hardcoding "
Featured Stories," your KMP web app could fetch actual articles from your Ktor backend:

```text
GET /api/home

HomeResponse(
    featuredStory = ...,
    trendingStories = ...,
    recommendedTopics = ...,
    featuredWriters = ...,
    latestStories = ...
)
```

That way, your web landing page becomes a **living front page of ScriptSide**, not just a static
marketing page. The same architecture would let you eventually personalize the page for logged-in
users while keeping the public landing page accessible to everyone.
